# 数据与操作

## 采集、分割、建模

1. 相机连接后点实时预览，调整物体，开始录制。相机 SDK2 提供帧对齐、深度比例和内参；采集代码将深度统一为毫米，并对裁剪/去畸变后的输出更新 K。
2. 停止后选择首帧，左键前景、右键背景，预览 SAM3 分割。目标应是建模物体。
3. 可以完整逐帧分割，也可以生成分段断点，在每段首帧点选同一物体。异常时停止，补点后重跑对应片段。完整 masks 不会被中途失败的结果覆盖；已完成且签名一致的片段可复用，无需手动删除所有 mask。
4. 验收导出后选择具体 `segment_001/` 开始训练，不能选择它的 dataset 父目录。位姿帧进度完成后还有全局神经场优化和贴图；以“全部完成”为准。
5. 模型默认在 `training_runs/run_*/reconstruction/textured_mesh.obj`。OBJ、MTL 和贴图必须保持同目录。可以在外部 3D 查看器中打开。

## 输入合同

```text
segment_001/
├── rgb/       # 同名 PNG，彩色
├── depth/     # 单通道 uint16 PNG，毫米，与 RGB 对齐
├── masks/     # 单通道 uint8 PNG，背景 0、目标 255
├── cam_K.txt  # 3×3 文本，必须对应最终 RGB 的分辨率/裁剪
└── metadata/  # 导出来源及检查报告
```

图像宽高必须一致，三个目录同名逐帧对应。采集帧名使用时间戳，导出保留对应关系。验收检查深度和 mask 类型、分辨率、前景腐蚀后面积、有效深度及连续性，过滤后至少 5 帧才导出训练片段。这是格式/可用性检查，不是姿态精度或模型质量评估。默认有效深度上限 1 m，可在界面调整。

## FoundationPose 离线新序列

录制同一物体的新序列 → 跟踪页面选新数据集 → 选之前 BundleSDF 建立的米制 OBJ → 首帧 SAM3 点选并确认 → 启动跟踪。这里仅需初始化帧 mask，后续由 FoundationPose refiner 跟踪，不必先分割全序列。长轴正对镜头、遮挡或有效几何不足时可能漂移；可以暂停、重新点选和初始化。叠加框正常不代表有真值验证的位姿准确度。

## 历史管理与删除

“文件量”是逻辑文件大小，导出共享的硬链接会重复计数；“预计单独释放”按 inode 链接数判断删除该条目后能释放的块。多选共同持有同一 inode 的所有链接时，预计释放可能高于单项之和。删除结果包含操作成功项与实际磁盘空闲变化；并发其他程序写盘、打开的文件或文件系统特性均可能使即时空闲变化不同。

历史页支持多选和删除确认。删除前会复查目录身份、活动任务、挂载边界和数据锁；软链接不跟随。删除是永久操作，工作区“清空”则只是卸载界面状态，二者不同。跨文件系统导出会回退复制，可能真实占用两份空间。
